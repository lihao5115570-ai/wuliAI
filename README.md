# ESP32 桌面陪伴机器人

## 项目目标

制作一台适合新手逐步完成的桌面陪伴机器人原型。第一版包含屏幕表情、声音输入、声音输出和触摸反馈；后续再加入舵机、Wi-Fi、国产 AI、定制 PCB 与 3D 打印外壳。

## 当前阶段

阶段 1：ESP32 本体。

当前只进行开发板外观与焊接安全检查，尚未通电。

## 已有硬件

- ESP32-S3 SuperMini 开发板
- 0.96 英寸 I2C OLED（GND / VCC / SCL / SDA）
- I2S 麦克风模块（具体型号待确认）
- MAX98357A I2S 功放模块
- 小喇叭（规格待确认）
- 面包板、杜邦线和基础焊接工具

## 工具使用原则

- 允许使用合适的插件、MCP 和外部工具，但必须降低新手理解与操作难度。
- 接线图优先采用接近实物的可视化形式，不用抽象原理图代替实际接线示意。
- 真实通电前可用 Wokwi 或类似工具验证其支持的程序与逻辑；不支持的真实模块必须明确标注“未仿真”。
- 当前不设计 PCB。只有面包板版本完全稳定后，才进入 KiCad、嘉立创 EDA 或 EasyEDA 阶段。
- 所有图、表、照片说明、测试程序和开发记录都保存在本项目目录。

详细规则见 [project_rules.md](project_rules.md)。

## 隐私与密钥安全

- Wi-Fi 密码、AI API 密钥和访问令牌不得提交到 Git 仓库。
- 私密配置使用 `secrets.h` 或 `.env` 保存；这些文件已由 `.gitignore` 排除。
